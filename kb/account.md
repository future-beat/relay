# Accounts and Access

## Password reset

Users reset passwords themselves at lanekeep.com/reset. Reset emails come from
no-reply@lanekeep.com and expire after 60 minutes. Support cannot set or read
passwords.

## Two-factor authentication

2FA (TOTP) is available on all plans. If a user loses their authenticator and
their recovery codes, identity must be verified by a human agent before 2FA can
be removed — the support assistant should escalate these cases with priority high.

## Data export and deletion

Workspace admins can export all workspace data (JSON/CSV) from **Settings →
Workspace → Export**. Account deletion requests are processed within 30 days and
are irreversible; they must be confirmed from the account owner's email address.

## SSO (Enterprise)

SAML SSO is configured under **Settings → Security → SSO**. Changes to SSO
configuration require a workspace owner and take effect within 15 minutes.
