<objective>
Adopt `Database.transaction()` in the five-writer set that lives below the HTTP edge (`tools.py`'s three writers and `telemetry.record_run`), open the single `asyncio.to_thread` offload seam in `agent.py` (D-01), and add the ticket-aware fake client that plan 02-05's concurrency test needs.

Purpose: `commit()` is connection-scoped. An INSERT+UPDATE pair that drops the lock between statements can be committed halfway through by another request, and its own rollback then undoes nothing — demonstrated on a real SQLite file by the researcher. The offload seam is what actually stops blocking the event loop; the transactions are what stop that from being a regression.

Output: three tool writers and `record_run` as single units of work; one new `await` in the agent loop; one appended test double.
</objective>
