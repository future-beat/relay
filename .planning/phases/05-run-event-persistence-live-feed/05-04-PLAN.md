<objective>
Serve the public live feed: a `GET /events` SSE route that subscribes to the broker, sends a projected snapshot of currently-running runs on connect (D-14), heartbeats during quiet periods and idle-closes after the ceiling (D-09), and unsubscribes in a `finally` (CR-02). Close the broker in `lifespan` beside the drain so open streams end promptly and the machine can still scale to zero (SC-4). This proves SC-2 and SC-4 without any Phase 6 dashboard UI.

Purpose: The live-feed transport and its two scale-to-zero guarantees — a viewer is not a run (D-12), and a forgotten tab cannot hold the machine awake (D-09). Fly autostops on active *connections*, so the app closing its own long-lived streams is the only thing that lets the machine reach `stopped`.

Output: Changed `main.py` (route + lifespan close); integration tests for the live smoke, disconnect-unsubscribe, heartbeat/idle-close, and viewer-is-not-a-run.
</objective>
