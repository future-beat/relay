<!-- Contracts this plan modifies. Extracted from the codebase — use directly, no exploration. -->

The page already holds `const DEMO_KEY = "__RELAY_DEMO_KEY__"`, substituted per request and rendering
`(not configured)` when `settings.demo_key` is unset (main.py's `dashboard()`).

`POST /tickets` takes `{customer_email, subject, body}` (models.TicketCreate, `customer_email` is an
EmailStr and is REQUIRED) and returns 201 with the ticket. `POST /tickets/{id}/process` streams SSE and,
after plan 06-04, returns `X-Relay-Run-Uid` plus `Cache-Control: no-cache` and `X-Accel-Buffering: no`.
Same-origin fetch reads response headers with no CORS allowlist needed.

`EventSource` takes only `(url, {withCredentials})` — no POST, no custom headers [CITED: MDN], so the
`X-API-Key` cannot be sent on it. The fetch + `\n\n`-buffered frame parser is written out at
06-RESEARCH.md:787-819; frames split across chunk boundaries, so a regex over the whole body only works
once the stream has ended, which defeats the point.

The `/process` stream is the OWNER-facing, full-fidelity stream (main.py:317-320, deliberately not the
projection) — the submitter sees their own run in full while the ambient `/events` feed shows the same
run redacted. Both render on this page at once, which is why the uid is needed to tell them apart.

Refusals the Try-it path can meet (06-RESEARCH.md:589-604), all with the note to render:
  POST /tickets   429 rate_limited            (demo_create_limit, 20/hour/IP)
  POST /process   429 rate_limited            (demo_process_limit, 5/hour/IP — the binding constraint)
  POST /process   503 daily_budget_exhausted  (detail.resets_at is an ISO timestamp — render it, never
                                               recompute midnight in JS)
  POST /process   429 rate_limited (outage)   (the ceiling refused AND the caller is retrying)
  POST /process   503 shutting_down           (a deploy is draining)
  either          401/503 with a PLAIN-STRING detail (no keys configured)
so the renderer must handle both shapes: `typeof detail === "string" ? detail : detail.note`.

The three examples, lifted verbatim from `evals/golden.jsonl` (ids `refund-monthly`, `rate-limits-pro`,
`password-reset`), pin seeded customer addresses — mia@datalane.ai, liam@brightco.io,
noah@freetier.dev — all of which `lookup_customer` can actually find. `evals/golden.jsonl` is DATA and
may be read; `src/relay/evals.py` is frozen and must not be touched.

Pitfall 14: `/dashboard` is hit anonymously with NO keys configured by two shipped tests. The form must
render disabled with copy rather than throwing during page setup when DEMO_KEY is "(not configured)".

The template's rules from plans 06-05/06-06 continue to apply: marker-delimited blocks, textContent and
createElement only, no CDN, no build step, and the case-sensitive string "None" nowhere in the document.
