<objective>
Move the page out of `main.py` into a packaged template (D-04), then make it the designed surface DASH-02 and DASH-04 describe: aggregate cards and an outcome-distribution bar chart from the SQL-computed `/metrics`, hand-built inline SVG for daily cost and daily p50/p95 latency (D-10), and a budget gauge that reads the gate's own arithmetic (D-11) — with the whole page rewritten onto `textContent` and `createElement`/`createElementNS`, and Phase 5's live-feed block carried across untouched.

Purpose: the extraction closes the anti-pattern CLAUDE.md names by name, and it is the precondition for a page that triples in size across the next two plans. The rendering rule has to widen with it: the drill-down and Try-it both render model-influenced strings, and a block-scoped rule does not cover them. The CI docker smoke is the only automated check that can see a template lost from the wheel — the pytest suite reads from the source tree either way.

Output: `src/relay/templates/dashboard.html`; a `main.py` with no HTML in it; an extended CI docker job; render and safety tests.
</objective>
