<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| MCP client (stdio) → tool registry | An external MCP client (Claude Desktop, an IDE) can invoke any exposed tool; there is no HTTP layer to authenticate it |
| Deploy environment → process config | Env vars / Fly secrets are the only source of credentials and thresholds; an omission is a security-relevant event |
| PyPI → runtime | A new third-party package enters the production image |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Elevation of Privilege | `mcp_server.create_server` write tier | mitigate | `mcp_allow_writes` defaults to `False`; a write requires the operator to set `RELAY_MCP_ALLOW_WRITES=true`. Proven by `test_default_server_is_read_only` |
| T-01-02 | Repudiation / Tampering | Stale docstring telling operators to set `=false` for read-only | mitigate | Docstring and `.env.example` corrected in Task 3 / Task 2; grep assertions in acceptance criteria prevent the stale string surviving |
| T-01-03 | Information Disclosure | `api_key` / `demo_key` in `Settings` | mitigate | Stored as plain optional attributes only; no logging of settings anywhere. Downstream plans are forbidden from putting key material into `extra={"ctx": ...}` because `JsonFormatter` flattens `ctx` to stdout |
| T-01-04 | Denial of Service | Unset thresholds falling back to permissive values | mitigate | Every threshold has an explicit conservative literal default (`max_daily_cost_usd=5.0`, `trust_proxy_header=False`); `extra="ignore"` means a typo'd env var silently keeps the safe default rather than crashing open |
| T-01-SC | Tampering | `pip install limits` | mitigate | RESEARCH.md Package Legitimacy Audit records `slopcheck install limits` → `[OK] limits (pypi)`, mature source repo `github.com/alisaifee/limits`, disposition **Approved**. No `[ASSUMED]`/`[SUS]` packages in this phase, so no blocking human checkpoint is required |
</threat_model>
