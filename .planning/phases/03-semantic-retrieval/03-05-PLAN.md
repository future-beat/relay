<objective>
Thread a per-run `retrieved_ids` set through the agent loop (mirroring the SEC-04 ticket binding), reject any `send_reply` citing an unretrieved id with a recoverable denial, emit a `guardrail` event for it, and emit a distinct `notice` event when retrieval degrades. Instruct the model to cite retrieved ids.

Purpose: This is RAG-04's integrity control and RAG-05's visibility signal. The denial MUST be recoverable so the model retries in-run — a rejected send_reply that ends the run trips `ended_without_action` and regresses the eval gate (the D-07 "Watch" / RESEARCH Pitfall 1). It is a near-verbatim copy of the already-tested SEC-04 path.
Output: modified `agent.py`, `prompts.py`, `models.py`, `tests/test_guardrails.py`.
</objective>
