    Create `tests/test_index.py`: `test_index_matches_kb` reads `kb/index.json` meta and asserts `meta["kb_sha256"] == kb_sha256()` (the SAME imported function), with a failure message pointing to `scripts/build_index.py`. Also assert `meta["model"]` and `meta["output_dimension"]` match `settings.voyage_model`/`voyage_dim`. This test makes zero Voyage calls.

    ALSO in `tests/test_index.py`: `test_build_index_embeds_with_input_type_document` — monkeypatch `httpx.post` (or the module's client) to a fake returning a well-formed 512-dim response, invoke the builder's embed path with a real key stubbed via monkeypatch (no network), and assert the **actual request body** carried `input_type="document"`. This closes D-09's silent-recall trap on the INDEX side: `input_type` must be captured from the real call, not read back from the static `meta` literal the script writes (a swapped literal would still "match" itself). No live Voyage key required.
